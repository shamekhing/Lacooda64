OPENJOEY2 — 120 CARD EFFECTS AS DUEL ASSEMBLY
==============================================

PROGRAM MODEL
-------------
These are card-definition programs. They use symbolic operands because a card
definition cannot know runtime card-instance addresses before a duel exists.
The runtime binder resolves SELF, CONTROLLER, OPPONENT, TARGET/REF, EVENT,
QUERY, LINKED and PERSIST operands into concrete SPACE/register operands and
then emits DuelISA instructions.

Core machine:
  SPACE   [a] [p:a] [p:z:a] [p:z:sl:a] [p:z:sl:c:a]
  CONTROL [turn][phase][step][chain][effect][pc]

Instruction families used below map onto DuelISA concepts:
  LOAD/STORE, SELECT, COUNT, MOVE, SUMMON, POSITION, EQUIP, COUNTER,
  CONTROL, NEGATE, RESTRICT, ALU/MODIFY, COMPARE/JUMP, DAMAGE, LP,
  RANDOM, EVENT/TRIGGER, CHAIN, SCHEDULE, LINK/PERSIST, HALT.

CARD 001  Zombie Tiger  [MONSTER]
--------------------------------------------------------------------------
ID   47693640
TEXT Once per turn, you can either: Target 1 "Decayed Commander" you control; equip this card to that target, OR: Unequip this card and Special Summon it in Attack Position. While equipped by this effect, the equipped monster gains 500 ATK/DEF. If the equipped monster destroys an opponent's monster by battle: Discard 1 random card from their hand. (A monster can only be equipped with 1 Union monster at a time. If the equipped monster would be destroyed by battle, destroy this card instead.)

  EFFECT 1  IGNITION
    FLAGS optional=1
    TEST         {pred=PHASE, phase=MAIN, player=PLAYER}
    JIF_FALSE    EFFECT_END
    TEST         {pred=IN_ZONE, subject=self, zone=MONSTER}
    JIF_FALSE    EFFECT_END
    TEST         {pred=FACE_UP, subject=self}
    JIF_FALSE    EFFECT_END
    CHOICE player=PLAYER count=1
      CASE 0:
        SELECT                name=equip_target player=PLAYER selection=TARGET selector=QUERY{controller=PLAYER, zones=[MONSTER], names=[Decayed Commander], face=FACE_UP, count={min=1, max=1}}
        EQUIP                 equipment=self target=equip_target
      CASE 1:
        REQUIRE               condition={pred=RELATION, relation=EQUIPPED_TO, a=self, b=equipped_monster}
        UNEQUIP               equipment=self
        SUMMON                method=SPECIAL subject=self player=PLAYER position=FACE_UP_ATTACK
    EFFECT_END:
    HALT.EFFECT

  EFFECT 2  CONTINUOUS
    FLAGS optional=0
    TEST         {pred=RELATION, relation=EQUIPPED_TO, a=self, b=equipped_monster}
    JIF_FALSE    EFFECT_END
    MODIFY                subject=equipped_monster field=ATK operation=ADD value=#500 duration=CONTINUOUS
    MODIFY                subject=equipped_monster field=DEF operation=ADD value=#500 duration=CONTINUOUS
    EFFECT_END:
    HALT.EFFECT

  EFFECT 3  TRIGGER
    FLAGS optional=0
    EVENT.MATCH EVENT(DESTROYED_BY_BATTLE)
    TEST         {pred=RELATION, relation=EQUIPPED_TO, a=self, b=equipped_monster}
    JIF_FALSE    EFFECT_END
    RANDOM                kind=CARD from=QUERY{controller=OPPONENT, zones=[HAND], count={min=1, max=1}} store=random_card
    MOVE                  method=DISCARD subject=REF(random_card) to=GY
    EFFECT_END:
    HALT.EFFECT

  EFFECT 4  CONTINUOUS
    FLAGS optional=0
    RESTRICT              subject=equipped_monster restriction=MAX_ONE_UNION_EQUIPMENT duration=CONTINUOUS
    EFFECT_END:
    HALT.EFFECT

  EFFECT 5  REPLACEMENT
    FLAGS optional=0
    EVENT.MATCH EVENT(WOULD_BE_DESTROYED)
    TEST         {pred=RELATION, relation=EQUIPPED_TO, a=self, b=equipped_monster}
    JIF_FALSE    EFFECT_END
    MOVE                  method=DESTROY subject=self to=GY cause=REPLACEMENT
    EFFECT_END:
    HALT.EFFECT
